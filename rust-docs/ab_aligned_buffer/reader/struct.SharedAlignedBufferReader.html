Struct SharedAlignedBufferReader

pub struct SharedAlignedBufferReader<'a, A>
where
    A: Alignment,
{ /* private fields */ }
Expand description

Reads the contents of a SharedAlignedBuffer front to back, see SharedAlignedBuffer::reader().

Bytes are borrowed from the buffer for as long as the buffer is borrowed, so any number of them can be held at once, while Self::read_buffer() creates buffers that reference a part of the contents without copying them.

A read that fails leaves the reader unchanged.

pub fn read_buffer<B>( &mut self, len: u32, ) -> Result<SharedAlignedBuffer<B>, ReadError>
where B: Alignment,

Create a buffer that references the next len bytes without copying them.

The bytes must be aligned to B in memory, Self::read_to_alignment() reads padding in front of them if necessary. The new buffer keeps the whole allocation alive unless it is empty, see SharedAlignedBuffer::into_standalone().

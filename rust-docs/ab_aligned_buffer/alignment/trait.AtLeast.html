Trait AtLeast

pub trait AtLeast<A>: Alignment
where
    A: Alignment,
{ }
Expand description

Alignment that is at least as strict as A, such that anything aligned to Self is also aligned to A

Dyn Compatibility§

This trait is not dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety".

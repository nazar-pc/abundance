Expand description

Creates hashers for trees with a known number of leaves.

A hasher either ignores the tree size, in which case it implements Default and gets this trait through the blanket implementation, or depends on it, in which case it implements this trait directly and must not implement Default. It can’t be both: the two implementations would conflict.

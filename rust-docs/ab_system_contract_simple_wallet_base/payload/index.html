Module payload 

Source
Expand description

This module contains generic utilities for serializing and deserializing method calls to/from payload bytes.

It can be reused to implement a different wallet implementation. TransactionPayloadCaller calls the methods of a payload one by one. TransactionPayloadDecoder in decoder checks a payload and describes its methods without calling them, for example to show a transaction on the screen of a hardware wallet before it is signed. Both use the same decoding code, so they apply the same rules.

Methods can pass values to later methods of the same payload through outputs. A payload declares all its outputs upfront, each with a capacity, and every #[output] and return value of a method writes one of them. Later methods can refer to what was written last into a declared output as a slot or an input, see TransactionOutput.

Builder interface requires heap allocations and can be enabled with payload-builder feature, while the rest works in no_std environment without a global allocator.

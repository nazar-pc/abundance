Struct Lent 

Source 
pub struct Lent<'a, T>
where
    T: IoType,
{ /* private fields */ }
Expand description

Memory lent to calls as an #[output], whose contents are parsed before they are accessed.

A call can leave contents behind that are not a valid value, for example when it fails halfway, so the contents are only accessible through Self::get_mut(), which parses them once after each call. Plain values can also be replaced with Self::set(). Memory whose contents accept every bit pattern can be given to calls directly, see OutputArg.

Created with Self::new() for a local value, with Lent::<MaybeData<_>>::from_uninit() or Lent::<VariableElements<_>>::from_uninit() for a local container, and with Env::lend_output() for an #[output] the method received.

§Safety

After the returned Lent was given to a call, value may hold contents that are not a valid value. Once the Lent is no longer used, the contents of value must not be accessed without being parsed first, unless the last use of the Lent after its last call was a successful Self::get_mut() or Self::set(), or the contents of T accept every bit pattern.

Source

pub fn get_mut(&mut self) -> Result<&mut T, ContractError>

Exclusive access to the contents, which are parsed once after each call.

Repeated calls without a call in between don’t parse the contents again. Returns ContractError::BadOutput if they are not a valid value of T. They then stay inaccessible until Self::set(), which only exists for plain values, replaces them. Lending them again doesn’t help either: methods generated by #[contract] reject outputs with invalid initial contents with ContractError::BadInput.

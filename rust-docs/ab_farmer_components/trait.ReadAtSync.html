Expand description

Sync version of ReadAt, it is both Send and Sync and is supposed to be used with a thread pool

Required Methods§

Source

fn read_at( &self, buffer: OwnedPages, len: u32, offset: u64, ) -> Result<OwnedAlignedBuffer<Align1>, IoBufError<OwnedPages>>

Read len bytes at offset into buffer, replacing its contents.

The allocation of the buffer is reused when possible and grows otherwise, allocation failure is returned as an error. Existing contents are never copied. On success, the contents are exactly the requested bytes. The buffer is returned back on error too.

The returned buffer can be reused for the next read with [OwnedAlignedBuffer::into_empty()].

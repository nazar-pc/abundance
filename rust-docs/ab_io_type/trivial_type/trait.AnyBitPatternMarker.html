Trait AnyBitPatternMarker 

Source 
pub unsafe trait AnyBitPatternMarker { }
Expand description

Every bit pattern of the type is a valid value.

Together with TrivialType it provides AnyBitPattern, which is the bound to use. #[derive(TrivialType)] implements it for structs whose fields all implement it, unless they use #[trivial_type(validate = path)].

§Safety

Every pattern of size_of::<Self>() initialized bytes is a valid value of Self that no invariant of Self excludes, not even one that only safe code relies on (like a length that must not exceed a capacity, or one that #[trivial_type(validate = path)] checks), so bytes of Self never need to be checked. If Self implements TrivialType, its parsing step TrivialType::try_from_bytes_unaligned() accepts every such pattern.

Dyn Compatibility§

This trait is dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety".

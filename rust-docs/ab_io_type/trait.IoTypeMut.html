Expand description

Exclusive access to an IoType value.

It is implemented for:

  • every IoType
  • views that constructors of containers return over exclusive memory, like MaybeData::from_mut() and VariableElements::from_uninit()

This allows generic code to accept both.

§Safety

Generic code relies on Self::io_type_mut() giving access to a single value owned by Self: every call returns a reference to the same value without changing it or anything else, and the value is not accessible other than through Self. Generic code may also move the value out of Self through that reference and forget Self right after, so the value must stay valid without Self.
